# Система мониторинга концентрация co₂

## Постановка задачи
Программа предназначена для мониторинга технологического процесса в химическом реакторе по параметру «концентрация CO₂» (X), измеряемому в процентах. Пользователь вводит значение концентрации, программа преобразует его в нормированный показатель Q(X) по заданной формуле и выводит результат. Формула выбирается в зависимости от значения X: при X < 2, при 2 ≤ X ≤ 8 или при X > 8.

В представленном коде реализовано преобразование одного показания. Оперативный контроль последовательности измерений и статистический анализ выборки не выполняются.

### Входные данные:
*   Параметр X: Концентрация CO₂ %.
*   Диапазон X: от 0 до 20 %.
*   Количество измерений в выборке: N = 70.

## Алгоритм
1. Начать программу
2. Настроить русский язык для вывода
3. Ввести значение X
4. Вычислить Q:
      * если X < 2, то Q = 2(X − 2) + 10;
      * иначе, если X ≤ 8, то Q = (X − 5)² + 45;
      * иначе Q = 3√(X − 8 + 1) + 55.
5. Вывести X и Q
6. Завершить программу
