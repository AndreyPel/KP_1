# Система мониторинга концентрации CO₂

## Постановка задачи
Программа предназначена для мониторинга технологического процесса в химическом реакторе по параметру «концентрация CO₂» (X), измеряемому в процентах. Пользователь вводит значение концентрации, программа преобразует его в нормированный показатель Q(X) по заданной формуле и выводит результат. Формула выбирается в зависимости от значения X.

### Входные данные:
* Параметр X: Концентрация CO₂ в %.
* Диапазон X: от 0 до 20 % ($0 \le X \le 20$).
* Количество измерений в выборке: N = 70.

### Преобразование показания
Показание датчика преобразуется по кусочной функции:

$$
Q(X) =
\begin{cases}
2(X - 2) + 10, & X < 2 \\
(X - 5)^2 + 45, & 2 \le X \le 8 \\
3\sqrt{X - 7} + 55, & X > 8
\end{cases}
$$

*Примечание:* Для третьей ветки подкоренное выражение $X - 7 \ge 0 \Rightarrow X \ge 7$. Поскольку эта ветка выполняется при $X > 8$, условие корректности квадратного корня выполняется автоматически. Поведение программы за пределами $0 \le X \le 20$ считается неопределённым (требует валидации на уровне ввода).

## Алгоритм
1. Начать программу.
2. Настроить русский язык для вывода (локаль).
3. Вывести приветствие и описание программы.
4. Считать значение X с помощью отдельной функции ввода.
5. Вычислить Q:
   * если $X < 2$, то $Q = 2 \cdot (X - 2) + 10$;
   * иначе, если $X \le 8$, то $Q = (X - 5)^2 + 45$;
   * иначе $Q = 3 \cdot \sqrt{X - 7} + 55$.
6. Вывести значения X и Q.
7. Вывести допустимый диапазон контроля и результат проверки состояния (Норма / Отклонение).
8. Завершить программу.

## Ручные тесты

### Тест 1. Нижний диапазон
Пусть:
$$X = 0$$
Так как $0 < 2$, используется первая формула:
$$Q = 2 \cdot (0 - 2) + 10$$
$$Q = 2 \cdot (-2) + 10$$
$$Q = -4 + 10$$
$$Q = 6$$
**Результат:**
X = 0.00, Q = 6.00
Состояние: Отклонение (6.00 вне диапазона [34.00; 56.00])

---

### Тест 2. Центральный диапазон
Пусть:
$$X = 5$$
Так как $2 \le 5 \le 8$, используется вторая формула:
$$Q = (5 - 5)^2 + 45$$
$$Q = 0^2 + 45$$
$$Q = 45$$
**Результат:**
X = 5.00, Q = 45.00
Состояние: Норма (45.00 = Q₀, находится в диапазоне [34.00; 56.00])

---

### Тест 3. Контрольный пример из задания
Пусть:
$$X = 2.00$$
Так как $2 \le 2 \le 8$, используется вторая формула:
$$Q = (2 - 5)^2 + 45$$
$$Q = (-3)^2 + 45$$
$$Q = 9 + 45$$
$$Q = 54$$
**Результат:**
X = 2.00, Q = 54.00
Состояние: Норма (54.00 находится в диапазоне [34.00; 56.00])
