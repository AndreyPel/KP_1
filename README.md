# Система мониторинга концентрация co₂

## Постановка задачи
Программа предназначена для мониторинга технологического процесса в химическом реакторе по параметру «концентрация CO₂» (X), измеряемому в процентах. Пользователь вводит значение концентрации, программа преобразует его в нормированный показатель Q(X) по заданной формуле и выводит результат. Формула выбирается в зависимости от значения X: при X < 2, при 2 ≤ X ≤ 8 или при X > 8.

### Входные данные:
*   Параметр X: Концентрация CO₂ %.
*   Диапазон X: от 0 до 20 %.
*   Количество измерений в выборке: N = 70.

### Преобразование показания

Показание датчика преобразуется по кусочной функции:

$$
Q(X) =
\begin{cases}
2(X - 2) + 10, & X < 2 \\
\dfrac{(X - 5)^2}{1} + 45, & 2 \le X \le 8 \\
3\sqrt{X - 8 + 1} + 55, & X > 8
\end{cases}
$$


## Алгоритм
1. Начать программу
2. Настроить русский язык для вывода
3. Ввести значение X
4. Вычислить Q:
      * если X < 2, то Q = 2(X − 2) + 10;
      * иначе, если X ≤ 8, то Q = (X − 5)² + 45;
      * иначе Q = 3√(X − 8 + 1) + 55.
5. Вывести X и Q
6. Завершить программу

## Контрольный пример

### Тест 1. Нижний диапозон

Пусть:

$$X = 0$$

Так как:

$$0 < 2$$

используется первая формула:

$$Q = 2 \cdot (0 - 2) + 10$$

$$Q = 2 \cdot (-2) + 10$$

$$Q = -4 + 10$$

$$Q = 6$$

**Результат:**

X = 0.00

Q = 6.00

Состояние: Отклонение (6.00 вне диапазона [34.00; 56.00])

---

### Тест 2. Центральный диапозон

Пусть:

$$X = 5$$

Так как:

$$2 \leq 5 \leq 8$$

используется вторая формула:

$$Q = \frac{(5 - 5)^2}{1} + 45$$

$$Q = \frac{0^2}{1} + 45$$

$$Q = 0 + 45$$

$$Q = 45$$

**Результат:**

X = 5.00

Q = 45.00

Состояние: Норма (45.00 = Q₀, в диапазоне [34.00; 56.00])


---

### Тест 3. Контрольный пример из задания

Пусть:

$$X = 2.00$$

Так как:

$$2 \leq 2 \leq 8$$

используется вторая формула:

$$Q = \frac{(2 - 5)^2}{1} + 45$$

$$Q = \frac{(-3)^2}{1} + 45$$

$$Q = \frac{9}{1} + 45$$

$$Q = 9 + 45$$

$$Q = 54$$

**Результат:**

X = 2.00

Q = 54.00

Состояние: Норма (54.00 в диапазоне [34.00; 56.00])
